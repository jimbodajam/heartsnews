# Isla standing sprite prompts

Run each as a fresh request, attaching `standing-master.jpg` (the full-length standing Isla, palm raised towards the screen). Never attach a previous variant.
Ask for PNG if possible. Keep the output the same size and framing as the master (848 x 1264, figure in the same place).

Every prompt below is complete: copy the whole block and paste it as is.

All of these are "change only the face" edits. The mouth is small and her head is turned slightly, so every prompt says to keep the mouth in the same position and the same size as the closed mouth in the master.

Order: 5 and 1 first (open and closed, the minimum to see lip-sync working), then 2, 3 and 4, and 6 last. The eye prompts (7 to 9) are optional because the blink and glances can also be made in code.

Check each result before keeping it: the mouth should be about as wide as the closed mouth in the master and sit in exactly the same place. If it comes out too big or off-centre, add "keep the mouth the same width as the original closed mouth" to the end of the prompt and run it again.
