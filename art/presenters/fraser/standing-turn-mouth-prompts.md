# Fraser turned-head mouth prompts

The code lays a front-view mouth over the nods and tilts, but a three-quarter turn changes the angle of the mouth, so (as with Isla's `h1v1`-`h1v6`) each turned head needs its own mouth frames.

Run each as a fresh request, attaching the turned head named in its section: `site/public/spike/fraser/standing/h1.jpg` (turn right) or `h2.jpg` (turn left). Never attach a previous variant or the master. Ask for PNG if possible. Keep the output 848 x 1264 with the figure in the same place and the same dull purple-pink background.

Save results next to the master as `h1v1.jpg` to `h1v7.jpg` and `h2v1.jpg` to `h2v7.jpg` (the number is the mouth: 1 smile, 2 parted, 3 ee, 4 oh, 5 ah, 6 pressed, 7 blink, same order as `v1`-`v7`).

Every prompt is a "change only the mouth (or eyes)" edit, so the head, the turn angle, the body and everything else must stay identical.

Check each result before keeping it: the head turned at exactly the same angle as the file you attached, and the mouth about as wide as the original closed mouth, in the same place. If the head moved or the mouth is too wide, add "keep the head and the mouth width exactly as in the original" to the end and run it again.

Order: 5 and 1 first (open and closed, the minimum to see lip-sync), then 2, 3 and 4, then 6, then the blink. Do `h1` first; `h2` only if the broadcast will use the left turn as much.
